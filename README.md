## 🌟 Funcionalidades do Portal

1. **Cartografia Histórica Interativa**:
   * Visualização com imagens reais de **Google Maps Satélite** e **Google Ruas**.
   * Levantamento de marcos históricos, culturais, religiosos e geomorfológicos de Tangará (IERN, Igreja Matriz do Sagrado Coração de Jesus, Estação Ferroviária Great Western, Mirante do Cruzeiro e Serra da Rajada).
   * Pins personalizados em alta resolução com detalhes, fotos e coordenadas exatas.

2. **Blog Editorial e Memorial**:
   * Publicação de matérias históricas e notícias com editor de texto rico (negrito, itálico, cabeçalhos, citações e listas).

3. **Canal de Vídeos Documentais**:
   * Incorporação de vídeos educativos e documentários com player oficial integrado.

4. **Painel do Historiador e Sistema de Login Criptografado**:
   * Autenticação e proteção com **Web Crypto API (SHA-256 e AES-GCM 256 bits)**.
   * Totalmente nativo no navegador: **sem custos com bancos de dados externos nem servidores pagos**.
   * Bloqueio contra força bruta (3 tentativas incorretas bloqueiam o acesso por 30 segundos).
   * Sistema de sincronização com botão **"Baixar index.html Pronto para o GitHub Pages"** para manter todas as alterações salvas para os visitantes da web.
